# 프론트 세션 작업 목록 (frontend 브랜치)

배포·인증 스펙: `2026-08-06-deployment-auth-design.md` 참고. 백엔드가 API 먼저 올린 뒤 착수 권장.

## 배포·인증 신규

1. **로그인 화면** — Supabase JS SDK, 구글 로그인 버튼 + 이메일/비번. 로그인 전 라우트 가드.
2. **온보딩 화면** — 로그인 후 무소속이면: "연구실 만들기"(이름 입력) / "초대 코드 입력" 두 갈래.
3. **API 클라이언트** — 모든 요청에 `Authorization: Bearer <supabase access token>` 첨부,
   401 → 로그인으로, 403(무소속) → 온보딩으로, 429(사용량 초과) → 안내 배너.
4. **연구실 설정 화면 (admin 전용)** — 연구실 이름, 초대 코드 표시·재발급,
   멤버 목록, 일일 사용량/상한 표시, LLM 모드 전환(중앙 ↔ 자기 크레덴셜 등록 폼).
5. **사이드바** — 연구실 이름·내 역할 표시 (기존 하드코딩 사용자 카드 대체).

## 기존 보류분 (백엔드 리뷰에서 나온 것)

6. **완성도 게이지 분모 버그** — `StructurePanel.tsx`: gaps에 단위 재질문이 추가돼
   분모(required_fields+required_parameters)와 안 맞음 → 필드 다 채워도 4/6 표시.
   단위 질문("의 단위를 알려주세요" 패턴)을 게이지 계산에서 제외하거나 서버 gaps 구조화 협의.
7. **notes(특이사항) 표시** — `types.ts`의 ParsedLog·RecordDetail에 `notes: string` 추가,
   ② 구조 패널·⑤ 연구노트 상세에 특이사항 필드 렌더. 백엔드는 이미 보냄.
