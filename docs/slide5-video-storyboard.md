# 슬라이드 5 영상 촬영 콘티 (30초, 실제 화면 녹화 + 모션그래픽)

발표 대본 슬라이드 5와 1:1 동기화. 무음 영상 — 발화가 나레이션을 대신한다.
빨간 라벨 문구는 발화 키워드와 **같은 단어**만 쓴다 (구조화 / 재질문 / 자동 정리 / 레코드 번호 / 관례 학습).

## 0. 사전 준비 (5분)

1. **서버**: 새 PowerShell 창에서 (로그인 화면 없는 로컬 모드로 촬영):

   ```powershell
   $env:HORCRUX_VAULT = "C:\Users\지완\labgene-demo-vault"
   cd C:\Users\지완\claude\horcrux\.claude\worktrees\web-impl
   horcrux serve
   ```

   데모 볼트(`labgene-demo-vault`)는 만들어뒀다 — 과거 기록 3건(HfO2 가장자리 편차
   사례 + 원인 확정 후속 + TiN 1건), 위키 2편, 관례 문서까지 시딩돼 있어 진단이
   근거를 풍부하게 단다.

2. **브라우저**: 시크릿 창, F11 전체화면, http://localhost:8765. 줌 110~125%
   (글자가 영상에서 읽히게). 북마크바 숨김.
3. **녹화**: Win+Alt+R (게임바) 또는 OBS, 1080p 이상. 마우스는 평소의 절반 속도로.
   각 컷은 넉넉히 찍고 편집에서 잘라낸다 — 파싱 대기 시간은 편집에서 점프컷.

## 1. 컷별 콘티

### 컷 1 (0~6초) — "실험이 끝나면 말하듯 연구결과를 던집니다"

- **화면**: 홈 → "실험 기록" 선택 → 입력창에 아래 로그를 붙여넣고 잠깐 멈춘 뒤 전송.
- **붙여넣을 로그 A** (일부러 증상·특이사항 언급 없음 — 재질문 유도):

  ```
  오늘 ALD로 HfO2 증착 다시 함. 이번엔 사이클을 350으로 올려봄. 온도 250도,
  압력 1.2, 오존은 80으로 유지. 두께는 11.7nm 나옴. 막질 확인은 다음주에 XRD로 할 예정.
  ```

- **후반**: 입력창으로 서서히 줌인 → 전송 클릭 순간까지. 라벨: **자연어 입력**
  (텍스트가 격식 없는 반말 로그라는 게 보이도록 입력창을 화면 중앙에).

### 컷 2 (6~12초) — "구조화된 연구노트로 정리하고, 빠진 조건은 되물어서"

- **화면**: 파싱 완료 후 화면. 오른쪽 구조 패널에 필드가 채워져 있고(제목·장비 ALD-02·
  파라미터에 단위 붙음 — 관례가 "ALD"→ALD-02, "250도"→250 °C로 채운 것),
  채팅에 AI 재질문("문제나 이상 증상이 있었나요?")이 떠 있다.
  칩 **"문제 없음"** 클릭 → 다음 질문("특이사항...") → 칩 **"특이사항 없음"** 클릭.
- **후반**: 구조 패널 줌인(0.5초 홀드) → 재질문 말풍선으로 팬. 라벨 2개:
  **AI 구조화** (패널 위), **재질문** (말풍선 위). 게이지(N/6)가 차오르는 순간 포함.

### 컷 3 (12~18초) — "장비·재료·실패사례를 구조화하여 자동으로 정리"

- **화면**: "검토 후 저장" → 미리보기에서 **저장하기** 클릭 → 연구노트 목록(제목 달린
  기록들) 1초 → 사이드바 **그래프뷰** 클릭 → 그래프에서 ALD-02 노드에 마우스 호버
  (연결된 실험들 하이라이트).
- **후반**: 노트 목록은 빠르게 스치고 그래프에서 머문다. 호버 하이라이트 순간 줌인.
  라벨: **자동 정리 — 장비·재료·실패사례**. (그래프의 장비/재료/원인 노드가 라벨의
  시각적 근거가 된다.)

### 컷 4 (18~24초) — "과거 사례를 레코드 번호까지 달아서 근거로 원인을 진단"

- **화면**: 홈 → "문제 질문" 선택 → 아래 질문 붙여넣고 전송 → 답변이 뜨면
  본문의 레코드 번호 부분과 오른쪽 유사 사례·참고 위키 목록이 보이게 스크롤.
- **붙여넣을 질문**:

  ```
  HfO2 증착에서 웨이퍼 가장자리 두께가 중앙보다 얇게 나오는 문제가 또 생기면
  뭐부터 확인해야 해? 과거 사례 근거로 알려줘.
  ```

  (시딩된 사례가 정확히 이 문제라 — 오존 유량 부족 확정 + 후속 실험 근거 —
  답변에 `2026-08-10_hfo2-ald-001` 형식 레코드 번호가 달려 나온다.)
- **후반**: 답변 텍스트의 레코드 번호에 **익스트림 클로즈업** + 빨간 밑줄 애니메이션.
  라벨: **레코드 번호 = 근거**. 유사 사례 카드로 팬하며 마무리.

### 컷 5 (24~30초) — "기록 습관까지 학습해서 같은 질문을 두 번 하지 않습니다"

- **화면**: 홈 → "실험 기록" → 아래 로그 B 붙여넣고 전송 → 이번엔 재질문 **없이**
  "필요한 정보가 모두 채워졌습니다. 검토 후 저장하세요."가 바로 뜬다.
- **붙여넣을 로그 B** (컷 1과 같은 유형, 이번엔 완결 — 관례+학습된 습관의 효과 연출):

  ```
  ALD HfO2 380사이클 추가 런. 온도 250도 압력 1.2 오존 80. 두께 12.6nm.
  문제 없었고 특이사항도 없음.
  ```

- **후반**: 컷 2의 재질문 장면과 **좌우 분할 비교**(전: 질문 2개 / 후: 질문 0개)로
  연출하면 "두 번 묻지 않는다"가 한눈에 박힌다. 라벨: **관례 학습 — 질문 0개**.
  마지막 1초: 화면 중앙에 LAB GENE 로고 텍스트 페이드인 (편집에서 삽입).

## 2. 편집 체크리스트 (CapCut 기준)

- [ ] 컷 경계는 슬라이드 5 발화의 문장 경계와 일치 (연습 녹음에 맞춰 미세 조정)
- [ ] 파싱 대기 구간은 점프컷 + 2배속 (로딩 애니메이션 1초만 남기기)
- [ ] 빨간 라벨: 고딕 볼드, 화면당 최대 2개, 지시선(꺾인 화살표)과 함께 등장 0.3초 슬라이드인
- [ ] 줌인·팬은 컷당 1회만 — 30초에 무빙이 많으면 어지럽다
- [ ] 음성·BGM 없음 (발표자가 라이브로 말함)
- [ ] 내보내기 1080p 30fps, 총 29초 내외 (30초를 꽉 채우지 말 것 — 발화가 밀리면 영상이 먼저 끝나는 게 낫다)

## 3. 촬영 전 리허설 팁

로그 A·B와 질문은 촬영 전에 한 번씩 실제로 돌려봐라 — LLM 응답은 매번 조금씩
달라서, 재질문이 예상(증상→특이사항 순 2개)과 다르게 나오면 로그 A에서 정보를
하나 더 빼거나 넣어 조정하면 된다. 진단 답변의 레코드 번호는 시딩 데이터 덕에
안정적으로 나온다.
